Main project · NLP, machine learning and deployment

What 1.16 million reviews say about Madrid's restaurants

A reputation tool for 10,056 restaurants. It summarises each restaurant, compares it with similar places, flags reputations that declined and classifies any review in Spanish or English, showing how much each word weighed in the decision.

The data were split by restaurant, so the final test used places the model had never seen. The model is served through a FastAPI service and tracked in MLflow.
